# Editorial Flip Clock

영상 편집에 사용할 디지털 플립 시계 애니메이션을 브라우저에서 만들고 영상으로 내보내는 도구입니다.

## 주요 기능

- 시작·도착 시간과 애니메이션 길이 지정
- 증가·감소 방향과 선형·부드러운 모션 선택
- 시계 및 단색 배경 색상 설정
- 키잉에 불리한 유사 색상 경고
- 1080p 또는 4K 영상 내보내기
- MP4 우선 저장 및 미지원 브라우저의 WebM 대체 안내
- 별도 출력 화면과 전체 화면 재생

## 사용하기

배포 주소: <https://rifi97.github.io/editorial-flip-clock/>

Final Cut Pro에서 배경을 제거하려면 시계와 구분되는 단색 배경으로 영상을 내보낸 다음 `Keyer` 효과로 해당 배경색을 제거합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

테스트와 프로덕션 빌드:

```bash
npm test
npm run build
```

## 브라우저 참고사항

- 영상은 설정한 길이만큼 실시간으로 녹화되므로 내보내는 동안 탭을 화면에 유지해야 합니다.
- 브라우저가 MP4 녹화를 지원하지 않으면 WebM으로 저장되며, Final Cut Pro 사용 전 MP4 또는 ProRes로 변환해야 합니다.
- 메모리 보호를 위해 1080p는 최대 120초, 4K는 최대 60초까지 내보낼 수 있습니다.
